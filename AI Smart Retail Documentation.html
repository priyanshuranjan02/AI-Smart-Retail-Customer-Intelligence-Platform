Section 01

Project Overview

Smart Retail AI is a full-stack intelligent retail platform that demonstrates real-world applications of AI/ML in the retail domain. It provides four core AI services — all predictions are logged, audited, and visualized in a live analytics dashboard with dark/light theme support.

👤
Customer Face Recognition
OpenCV + Cosine Similarity
Identifies returning VIP loyalty customers from uploaded photos or live webcam snapshots. Logs every visit with timestamp and confidence score.
📦
Product Classification
HSV Features + SVM/RF
Classifies retail product images into 5 categories: Shoes, Clothes, Electronics, Groceries, Bags. Displays OpenCV preprocessing metadata.
💬
Sentiment Analysis
TF-IDF + Logistic Regression
Classifies customer reviews as Positive, Negative, or Neutral. Shows cleaned & lemmatized tokens with full NLP preprocessing pipeline.
🤖
Hybrid FAQ Chatbot
Rule Engine + ML Classifier
Three-tier chatbot: exact rule matching → ML intent classification → fallback. Handles store hours, returns, shipping, loyalty rewards, and more.
📊
Analytics Dashboard
Chart.js + SQLite Audit Logs
Live dashboard with 4 Chart.js visualizations: daily activity, sentiment distribution, product distribution, and recent face recognition visits.

Section 04

Database & Storage

💡
All runtime data lives in a single SQLite file

No external database server needed. SQLAlchemy auto-creates it with all 5 tables on first startup via init_db(). The database URL is configured in app/config.py.

smart-retail-ai/smart_retail.db

The face recognition module also stores customer face encodings in a separate Pickle file. No actual photos are ever stored — only the 384-dimensional mathematical feature vectors.

📁 Face Encodings File: app/models/face_db.pkl — Grows as new VIP customers are registered. Holds a Python dict of { customer_code → { encoding: [384-dim vector], name: "..." } }

Section 06

FastAPI Backend Server

📄 app/main.py — Entry Point
  • FastAPI app + Swagger UI at /docs
  • CORS middleware (all origins in dev)
  • X-API-Key security on all routes
  • Startup: init_db() + pipeline.initialize()
⚙️ app/config.py — Settings
  • API Key: smart-retail-secret-key-2026
  • DB URL: sqlite:///./smart_retail.db
  • Face Threshold: 0.6 cosine similarity
  • Image Target: (224, 224) pixels
🧠 app/pipeline.py — ML Singleton

Loads all 4 trained model .pkl files once at startup into memory. Uses Python's Singleton pattern so models are never reloaded per request.

🗄️ app/database.py — ORM

SQLAlchemy declarative models for all 5 tables. SessionLocal factory with check_same_thread: False for SQLite multithread safety. get_db() dependency injection.

🔧 Services Layer
cv_service.py
  • Image bytes → OpenCV BGR
  • Gaussian Blur (5×5 kernel)
  • Canny Edge Detection
  • HSV + Spatial feature extraction
  • Haar Cascade face detection
  • 384-dim face encoding
  • Cosine similarity matching
nlp_service.py
  • Lowercase + URL/HTML strip
  • Punctuation & digit removal
  • NLTK word_tokenize
  • Stopword removal
  • WordNet lemmatization
  • TF-IDF vectorization
  • Lexicon fallback
chatbot_service.py
  • Load intents.json rules
  • Tier 1: Rule/keyword match
  • Tier 2: ML intent classifier
  • Tier 3: Fallback response
  • Confidence threshold: 0.40
  • Random response from pool

Section 08

ML Models & AI Pipeline

👤
Model 1 — Customer Face Recognition
Cosine Similarity · OpenCV Haar Cascade
Features: 384-dim normalized vector Detection: Haar Cascade XML Threshold: 0.6 cosine similarity Encoding: 16×16 spatial + 4×4 LBP histograms
app/models/face_db.pkl
📦
Model 2 — Product Image Classifier
Random Forest / SVM · Scikit-learn
Features: 304-dim HSV histogram + spatial grid Classes: Shoes, Clothes, Electronics, Groceries, Bags Preprocessing: Gaussian Blur → Canny Edges → HSV histogram Fallback: Deterministic feature-sum modulo rule
app/models/product_classifier.pkl
💬
Model 3 — Sentiment Analysis
Logistic Regression · TF-IDF Vectorizer · NLTK
Classes: Positive, Negative, Neutral Preprocessing: lowercase → clean → tokenize → lemmatize Vectorizer: sklearn TfidfVectorizer Fallback: Seed word lexicon counter
app/models/sentiment_model.pkl + sentiment_vectorizer.pkl
🤖
Model 4 — FAQ Chatbot Intent Classifier
Rule Engine → Logistic Regression → Fallback (3-tier hybrid)
Intents: greeting, store_hours, return_policy, order_tracking, payment, shipping, discount, complaint, product_info, farewell Rule source: data/intents.json ML threshold: ≥ 0.40 confidence
app/models/chatbot_model.pkl + chatbot_vectorizer.pkl

End-to-End Data Flows

👤 Face Recognition Flow
1
User uploads/captures photo
FormData POST /vision/recognize-face
2
Image → OpenCV BGR array
PIL decode → cv2 color convert
3
Haar Cascade face detection
Returns bounding box (x, y, w, h)
4
Compute 384-dim face encoding
Spatial + LBP block histograms → normalize
5
Cosine similarity vs face_db.pkl
≥ 0.6 = Known customer, else Unknown
✓
Save to DB + return result
→ customer_visits + predictions tables
📦 Product Classification Flow
1
User uploads product image
FormData POST /vision/classify-product
2
OpenCV preprocessing
Resize 224×224 → Gaussian Blur → Canny edges
3
Extract 304-dim feature vector
HSV histograms (48) + spatial grid (256)
4
ML classifier predict_proba()
5 category probability scores
✓
Save to DB + return result
→ predictions table + frontend probability bars
💬 Sentiment Analysis Flow
1
User types review text
POST /nlp/analyze-sentiment {"text":"..."}
2
NLTK preprocessing pipeline
lowercase → clean → tokenize → lemmatize
3
TF-IDF vectorization
Sparse matrix → Logistic Regression
4
predict_proba() → class scores
[Positive, Negative, Neutral] probabilities
✓
Save + return sentiment + tokens
→ reviews + predictions tables
🤖 Chatbot Flow
1
User sends message
POST /chatbot/message {"message":"..."}
2
Tier 1: Rule-based matching
Substring/keyword match vs intents.json patterns → confidence 0.95
3
Tier 2: ML intent classification
TF-IDF + Logistic Regression (if ≥ 0.40 threshold)
4
Tier 3: Fallback response
Random generic reply at confidence 0.20
✓
Save + return response
→ chat_logs + predictions tables

Step 2 — Frontend Setup (Node.js) — Open a new terminal
# Navigate to frontend directory cd smart-retail-ai/frontend # Install Node.js packages npm install # Start the Vite development server npm run dev # App opens at http://localhost:3000
